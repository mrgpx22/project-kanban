# 📋 Kanban Board

Aplicación web de gestión de tareas y proyectos con múltiples vistas y herramientas integradas.

## ✨ Funcionalidades

- **Tablero Kanban** — Organización de tareas por columnas con drag & drop
- **Calendario** — Visualización de tareas y deadlines en formato mensual
- **Diagrama de Gantt** — Planificación temporal de proyectos
- **Notas** — Espacio para apuntes rápidos vinculados a proyectos

## 🛠️ Tecnologías

- HTML5 / CSS3 / JavaScript
- Supabase (base de datos y autenticación)

## 🚀 Instalación local

```bash
git clone https://github.com/tu-usuario/kanban.git
cd kanban
```

Configura tus credenciales de Supabase en el archivo de configuración y abre `index.html` en tu navegador.
